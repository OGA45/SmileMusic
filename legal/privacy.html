プライバシーポリシー

最終更新日: 2026年7月3日

本プライバシーポリシーは、個人（以下「開発者」）が趣味で開発・提供する Discord 音楽 BOT および Discord アクティビティ「SmileMusic」（以下「本サービス」）における、利用者の情報の 取り扱いについて定めるものです。

1. 収集する情報

本サービスは、機能の提供のために以下の情報を取得・保存します。

  • Discord の識別情報: ユーザー ID、ユーザー名、アバターのハッシュ値。
  • サーバー（ギルド）情報: 本サービスが利用されている Discord サーバーの ID。
  • 再生履歴: 再生した楽曲のタイトル・URL、操作したユーザー ID、サーバー ID、再生日時。
  • プレイリスト情報: 利用者が作成したプレイリストの名称、タグ、収録トラック（タイトル・URL・サムネイル・再生時間）。
  • ライブラリ共有情報: サーバー内で共有されたプレイリストと、それを追加した利用者の ID・名前・アバター。
  • 表示・オーディオ設定: テーマカラー、ビジュアライザーの種類、音量正規化などの UI 設定。

2. 情報の利用目的

  • 音楽再生・キュー・プレイリストなど、本サービスの各機能の提供および再生状態の管理。
  • 利用者ごとの設定・プレイリスト・履歴の保存と復元。
  • 本サービスの不具合調査・障害解析・デバッグ、および品質改善。取得した情報は、これらの目的の範囲で開発者が自由に閲覧・利用することがあります。

3. 情報の保存

上記の情報は、開発者が管理する PostgreSQL データベースに保存されます。開発者は、収集した 情報を第三者の広告・解析事業者へ提供したり、販売・貸与したりすることはありません （前項の運用・デバッグ目的での開発者自身による利用を除きます）。

4. Discord アクセストークンの取り扱い

Discord アクティビティの認証では Discord のアクセストークンを利用しますが、これは認証時の 一時的な利用にとどめ、データベース等に保存することはありません。

5. 外部サービスへの送信

本サービスは、楽曲の検索・再生のために以下の外部サービスと通信します。

  • YouTube・Spotify・ニコニコ動画など: 楽曲やプレイリストの URL・検索語のみを送信します。利用者の Discord ユーザー ID など個人を特定する情報は送信しません。各サービスの情報の取り扱いは、それぞれのプライバシーポリシーに従います。
  • Jellyfin: 開発者が用意したプライベートなメディアサーバーとの通信であり、外部への情報送信は伴いません。
  • サムネイル画像: 外部 CDN の画像は、本サービスのプロキシ経由で取得します（内部ネットワークへのアクセスは遮断しています）。

6. ログの取り扱い

障害解析のため動作ログを出力することがありますが、アクセストークンや API キーなどの秘密情報は マスク処理を行い、そのままの形ではログに残さないようにしています。

7. データの削除・開示のご請求

ご自身に関する情報（再生履歴・プレイリスト等）の削除や開示をご希望の場合は、下記の お問い合わせ先までご連絡ください。ご本人確認のうえ、合理的な範囲で対応します。

8. 本ポリシーの変更

開発者は、必要に応じて本ポリシーを変更することがあります。変更後の内容は本ページに掲載した 時点から効力を生じるものとします。
