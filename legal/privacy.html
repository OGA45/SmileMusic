プライバシーポリシー

最終更新日: 2026年10月9日
効力発生日: 2026年10月16日（それまでの間は、改定前の内容が適用されます）

本プライバシーポリシー（以下「本ポリシー」）は、個人（以下「開発者」）が趣味で開発・提供する Discord 音楽 BOT および Discord アクティビティ「OGA_Music」（旧名称「SmileMusic」。アルファ版・ベータ版を含みます。以下「本サービス」）における、利用者の情報の取り扱いについて定めるものです。

1. 取得する情報

本サービスは、「情報の利用目的」に記載した目的のために以下の情報を取得し、必要なものを保存します。

  • Discord の識別情報: ユーザー ID、表示名（未設定の場合はユーザー名）、アバターのハッシュ値、およびそれらの記録日時（アクティビティを開いただけの場合を含め、本サービスを利用したときに記録し、適宜更新します）。
  • サーバー（ギルド）情報: 本サービスが参加している Discord サーバーの ID・名前・アイコン・メンバー数、本サービスがそのサーバーを確認した日時、サーバーごとの設定、およびお知らせの配信記録。
  • 再生履歴: 再生した楽曲のタイトル・URL、操作したユーザーの ID・表示名（未設定の場合はユーザー名）、サーバー ID、再生日時。
  • プレイリスト情報: 利用者が作成したプレイリストの名称、タグ、作成日時、収録トラック（タイトル・URL・サムネイル・再生時間）。
  • ライブラリ共有情報: サーバーのライブラリに追加されたプレイリストと、それを追加した利用者のユーザー ID・ユーザー名・アバターのハッシュ値、追加日時。
  • アクティビティの設定: 表示や動作に関する設定（テーマカラーなど）、および最後に使用したプレイリスト。
  • 参加サーバーの一覧: アクティビティの利用時に、利用者が参加しているすべての Discord サーバーの一覧（サーバー ID・名称など）を Discord から取得します。この一覧は、アクティビティを開いたサーバーに利用者が参加しているかの確認にのみ使い、データベースには保存しません。
  • Discord から受信する情報: BOT は、導入されたサーバーのメンバー一覧、ボイスチャンネルへの参加状況、チャンネルの一覧と権限、メッセージ、オンライン状態などの情報を Discord から受信します。本サービスは、これらの情報を「情報の利用目的」に記載した目的の範囲内で利用します（名前の表示、サーバー情報の記録、ボイスチャンネルへの接続、操作できる利用者の確認、お知らせの配信、無人になったときの自動切断など）。メッセージの本文とオンライン状態は、現在、本サービスでは利用していません。
  • 動作ログ: 「ログの取り扱い」に記載する情報。
  • お問い合わせの内容: お問い合わせやご請求をいただいた場合のメールアドレス、お名前、お問い合わせの内容。

2. 情報の利用目的

  • 音楽再生・キュー・プレイリスト・ライブラリなど、本サービスの各機能の提供および再生状態の管理。
  • 利用者ごとの設定・プレイリスト・履歴の保存と復元、および「他の利用者に表示される情報」に記載した表示。
  • 本サービスの運用・管理。開発者がサーバーごと・利用者ごとの再生状況・再生回数・再生履歴を確認・集計し、本サービスの負荷や利用状況の把握、および不正な利用や利用規約に違反する行為の発見に用いること、ならびに履歴などに表示する名前を Discord から取得して更新すること（サーバーを退出した利用者を含みます）を含みます。
  • 本サービスの不具合調査・障害対応。
  • 本サービスの開発・改善。この目的には、特定の個人を識別できないように集計・加工した情報を用います（不具合の再現など、本サービスの提供・維持に必要な場合を除きます）。
  • 取得した情報から、特定の個人を識別できないように集計・加工した統計情報を作成すること。
  • メンテナンスや仕様変更などのお知らせの配信。
  • 利用規約に違反する行為への対応、および本サービスの利用の制限・停止。
  • お問い合わせやご請求への対応。

開発者は、上記の利用目的の範囲内で、取得した情報を自由に閲覧・分析・利用できるものとします。

3. 他の利用者に表示される情報

本サービスの機能上、以下の情報は同じ Discord サーバーの他の利用者にも表示されます。

  • 再生履歴: サーバー内の誰でも、コマンドでそのサーバーでの再生履歴（楽曲のタイトル・URL、再生した利用者の名前または ID、再生日時）を表示でき、その結果はコマンドを実行したチャンネルに表示されます。ご自身の履歴を表示した結果も同様です。
  • 楽曲の追加者: 曲をキューに追加すると、追加した利用者の表示名とアバターが BOT のメッセージやアクティビティのキューに表示されます。
  • 再生中のプレイリスト: アクティビティでプレイリストを再生すると、そのプレイリストの名称と収録トラックの一覧（タイトル・URL・サムネイル・再生時間）が、そのサーバーでアクティビティを利用するすべての利用者に表示されます。ライブラリに追加していないご自身のプレイリストも同様です。
  • ライブラリ: ライブラリに追加されたプレイリスト（名称・タグ・収録トラック）と、追加した利用者のユーザー名・アバターは、そのサーバーでアクティビティを利用するすべての利用者に表示されます（プレイリスト作成者と追加した利用者のユーザー ID もアクティビティに送信されます）。

4. 情報の保存と保存期間

「取得する情報」のうち、Discord の識別情報、サーバー情報、再生履歴、プレイリスト情報、ライブラリ共有情報、アクティビティの設定は、データベースに保存します。このうち、再生履歴、Discord の識別情報、サーバー情報、アクティビティの設定は、期間を定めずに保存します。プレイリストとライブラリ共有情報は、本サービス上で削除されるまで保存されます。お問い合わせの内容は、対応およびその記録に必要な期間保存します。本サービスの提供を終了した場合（アルファ版・ベータ版のみを終了した場合は、その版について）は、法令により保存が必要な情報、お問い合わせ・ご請求への対応の記録、および特定の個人を識別できないように集計・加工した統計情報を除き、本サービスが保存している情報を削除します。保存されている情報の削除をご希望の場合は、「開示・訂正・削除等のご請求」の方法でご請求ください。

5. 第三者への提供

開発者は、取得した情報を、個人情報の保護に関する法律その他の法令で認められる場合を除き、ご本人の同意なく第三者に提供しません。利用者は、本サービスを利用することにより、「他の利用者に表示される情報」に記載した情報が同じ Discord サーバーの利用者に表示されることに同意したものとします。また、「外部サービスとの通信」に記載のとおり、外部サービスを経由して情報が処理される場合や、情報の取り扱いを外部の事業者に委託する場合があります。特定の個人を識別できないように集計・加工した統計情報は、本項の対象外とします。

6. 外部サービスとの通信

本サービスは、機能の提供のために以下の外部サービスと通信します。

  • Discord: BOT の動作やアクティビティの認証などのために Discord と通信します。アクティビティの通信は Discord のプロキシを経由します。アクティビティの認証に使う Discord のアクセストークンは、本サービスへの接続時の本人確認と参加サーバーの確認にのみ使用し、データベースには保存しません。
  • Cloudflare: 本サービスのウェブページ（本ページを含みます）とアクティビティの通信（認証情報その他の利用者の情報を含みます）は、Cloudflare, Inc.（米国）のネットワークを経由する場合があります。また、これらのウェブページとアクティビティの画面には Cloudflare Web Analytics の計測スクリプトが組み込まれており、閲覧したページの URL・参照元・ブラウザの種類・IP アドレス等の情報が、利用者の端末から Cloudflare, Inc. に直接送信され、同社によって処理される場合があります。開発者は、同社が集計した統計情報を、本サービスの利用状況の把握などに利用します。同社による情報の取り扱いについては、Cloudflare のプライバシーポリシーをご覧ください。
  • YouTube・ニコニコ動画・SoundCloud・Bandcamp・SUNO など: 楽曲やプレイリストの取得に必要な URL・検索語・ID などを送信します。利用者の Discord ユーザー ID など、利用者を識別する情報は送信しません。各サービスの情報の取り扱いは、それぞれのプライバシーポリシーに従います。
  • YouTube API サービス: 本サービスは、動画・再生リストの情報（タイトル・サムネイル・再生時間など）の取得に YouTube API サービスを使用しています。Google による情報の取り扱いについては、Google プライバシーポリシーをご覧ください。

また、開発者は、本サービスの運用・管理、不具合調査・障害対応、および開発・改善のために、外部の事業者が提供するクラウドサービスや、AI を利用した開発支援サービス（米国の事業者が提供するものを含みます）を利用しています。その際、動作ログやデータベースに保存された情報の一部（Discord サーバー名・サーバー ID、ユーザー名・ユーザー ID、楽曲のタイトル・URL、再生履歴、日時など）が、これらのサービスに送信され、処理される場合があります。開発・改善のために利用する情報の扱いは、「情報の利用目的」に記載したとおりです。開発者は、これらのサービスの利用を、利用目的の達成に必要な範囲での情報の取り扱いの委託として行います。利用するサービスは変更されることがあります。

7. ログの取り扱い

障害解析などのため、本サービスは動作ログを記録しています。動作ログには、Discord サーバー名・サーバー ID、ユーザー名・ユーザー ID、楽曲のタイトル・URL、日時、本サービスへのリクエストの内容などが含まれることがあります。動作ログは、原則として30日を経過した後に自動的に削除されます。ただし、動作ログがそれより長く保持されることがあります。

8. 安全管理措置

開発者は、取得した情報の漏えい等を防ぐため、次の措置を講じています。

  • 取得した情報へのアクセス権限は、開発者が管理しています。
  • 利用者の認証とアクセス制御を行っています。
  • アクティビティとの通信は暗号化しています。
  • 外国（米国）の事業者である Cloudflare, Inc. のサービスや、米国の事業者が提供する AI を利用した開発支援サービスを利用しており、利用者の情報が米国で取り扱われる場合があります。米国の個人情報の保護に関する制度を把握したうえで、上記の措置を講じています。米国の制度については、個人情報保護委員会のウェブサイトで公表されている情報をご参照ください。

Cloudflare, Inc. および開発支援サービスを提供する米国の事業者による情報の取り扱いが外国にある第三者への個人データの提供に当たる場合に備え、開発者は、各社が個人情報の保護に関する法律第4章第2節の規定により講ずべきこととされている措置に相当する措置（以下「相当措置」）を継続的に講ずるための体制を整備していることを、各社の利用条件およびデータの取り扱いに関する定めにより確認しています。開発者は、法令に従い、各社による相当措置の継続的な実施を確保するために必要な措置を講じます。

9. 開示・訂正・削除等のご請求

プレイリスト（収録曲と、サーバーのライブラリへの登録を含みます）は、アクティビティからご自身で削除できます。再生履歴・Discord の識別情報・アクティビティの設定など、それ以外の情報について、利用目的の通知、開示（第三者提供記録の開示を含みます）、訂正・追加・削除、利用停止・消去、第三者への提供の停止（以下「開示等」）をご希望の場合は、「運営者・お問い合わせ先」のメールアドレス宛てに、Discord のユーザー ID とご請求の内容を記載したメールをお送りください。開示等のご請求は、この方法に限り受け付けます。ご本人確認（ご請求に係る Discord アカウントからのご連絡をお願いすることがあります）のうえ、本サービスが保存している該当情報を対象に、法令に従って対応します。代理人によるご請求の場合は、代理権を確認できる資料をあわせてお送りください。開示は、原則として電磁的記録をメールでお送りする方法で行います。なお、削除後に本サービスを再度ご利用になると、その時点の情報があらためて保存されます。

10. 本ポリシーの変更

開発者は、必要に応じて本ポリシーを変更することがあります。その場合は、民法その他の法令の定めに従い、本ポリシーを変更する旨、変更後の内容および効力発生日を、本ページへの掲載その他の適切な方法で周知します。利用目的を変更する場合は、法令に従い、変更後の利用目的を本ページで公表します。
