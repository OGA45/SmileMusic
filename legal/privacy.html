プライバシーポリシー

最終更新日: 2026年10月7日
効力発生日: 2026年10月7日

本プライバシーポリシー（以下「本ポリシー」）は、個人（以下「開発者」）が趣味で開発・提供する Discord 音楽 BOT および Discord アクティビティ「OGA_Music」（旧名称「SmileMusic」。アルファ版・ベータ版を含みます。以下「本サービス」）における、利用者の情報の取り扱いについて定めるものです。

1. 取得する情報

本サービスは、「情報の利用目的」に記載した目的のために以下の情報を取得し、必要なものを保存します。

  • Discord の識別情報: ユーザー ID、表示名（未設定の場合はユーザー名）、アバターのハッシュ値、およびそれらを最初と最後に記録した日時。アクティビティを開いたとき（曲を再生しなくても）や曲を再生したときなどに記録し、その後も適宜更新します。
  • サーバー（ギルド）情報: 本サービスが参加している Discord サーバーの ID・名前・アイコン・メンバー数と、本サービスがそのサーバーを初めて／最後に確認した日時。あわせて、サーバーごとの設定（音量、ストリーム再生の有効／無効、お知らせチャンネルの ID）と、お知らせの配信記録（配信先のサーバー名・チャンネル名）。
  • 再生履歴: 再生した楽曲のタイトル・URL、操作したユーザーの ID・表示名（未設定の場合はユーザー名）、サーバー ID、再生日時。
  • プレイリスト情報: 利用者が作成したプレイリストの名称、タグ、作成日時、収録トラック（タイトル・URL・サムネイル・再生時間）。
  • ライブラリ共有情報: サーバーのライブラリに追加されたプレイリストと、それを追加した利用者のユーザー ID・ユーザー名・アバターのハッシュ値、追加日時。
  • アクティビティの設定: テーマカラー、ビジュアライザーの種類、背景・ビジュアライザーの色付けの有無、前回使用したプレイリストを自動で選択するか・作成したプレイリストをライブラリに自動で追加するかの設定、および最後に使用したプレイリスト。
  • 参加サーバーの一覧: アクティビティから本サービスに接続するたびに（再接続を含みます）、Discord の OAuth2 認証（guilds 権限）により、利用者が参加しているすべての Discord サーバーの一覧（サーバー ID・名称など）を Discord から取得します。この一覧は、アクティビティを開いたサーバーに利用者が参加しているかの確認にのみ使い、データベースへの保存やログへの記録は行いません。
  • Discord から受信する情報: BOT は、導入されたサーバーのメンバー一覧、ボイスチャンネルへの参加状況、チャンネルの一覧と権限、メッセージ、オンライン状態などの情報を Discord から受信します。本サービスは、これらの情報を「情報の利用目的」に記載した目的の範囲内で利用します（名前の表示、サーバー情報の記録、BOT の接続先の決定、操作できる利用者の確認、お知らせの配信先の決定と設定画面での表示、管理画面での状態の表示、無人になったときの自動切断など）。メッセージの本文とオンライン状態は、現在、本サービスでは利用していません。また、本項に挙げたもの以外をデータベースに保存することはありません。
  • 動作ログ: 「ログの取り扱い」に記載する情報。
  • お問い合わせの内容: お問い合わせやご請求をいただいた場合のメールアドレス、お名前、お問い合わせの内容。

2. 情報の利用目的

  • 音楽再生・キュー・プレイリスト・ライブラリなど、本サービスの各機能の提供および再生状態の管理。
  • 利用者ごとの設定・プレイリスト・履歴の保存と復元、および「他の利用者に表示される情報」に記載した表示。
  • 本サービスの運用・管理。開発者が管理画面や統計画面で、サーバーごと・利用者ごとの再生状況・再生回数・再生履歴を確認・集計し、本サービスの負荷や利用状況の把握、および不正な利用や利用規約に違反する行為の発見に用いること、ならびに履歴などに表示する名前を Discord から取得し直すこと（サーバーを退出した利用者を含みます）を含みます。
  • 本サービスの不具合調査・障害対応・デバッグ。
  • 本サービスの開発・改善。新しい機能の動作確認や不具合の再現のために、保存されている情報を確認・利用することを含みます。
  • 取得した情報を、特定の個人を識別できないように集計・加工した統計情報（総再生数、楽曲・配信元・時間帯・サーバーごとの再生数など）に加工すること。
  • メンテナンスや仕様変更などのお知らせを、サーバー管理権限を持つ利用者が設定したチャンネル（未設定の場合や、設定したチャンネルに投稿できない場合はサーバーのシステムチャンネル）へ配信すること。
  • 利用規約に違反する行為への対応、および本サービスの利用の制限・停止。
  • お問い合わせやご請求への対応。

開発者は、上記の利用目的の範囲内で、取得した情報を自由に閲覧・分析・利用できるものとします。また、上記により作成した統計情報は、特定の個人を識別できる情報を含まないため、本サービスに限らず、開発者が開発・提供するサービス・ソフトウェアの開発・改善・研究その他の目的に、自由に利用できるものとします。

3. 他の利用者に表示される情報

本サービスの機能上、以下の情報は同じ Discord サーバーの他の利用者にも表示されます。

  • 再生履歴: /histry コマンドはサーバー内の誰でも実行でき、そのサーバーでの再生履歴（楽曲のタイトル・URL、再生した利用者の表示名、再生日時）が、コマンドを実行したチャンネルに表示されます。サーバーを退出した利用者は、ユーザー名または ID で表示されます。ご自身の履歴を表示する /histry_user の結果も、同じようにチャンネルに表示されます。
  • 楽曲の追加者: 曲をキューに追加すると、追加した利用者の表示名とアバターが BOT のメッセージやアクティビティのキューに表示されます。
  • 再生中のプレイリスト: アクティビティでプレイリストを再生すると、そのプレイリストの名称と収録トラックの一覧（タイトル・URL・サムネイル・再生時間）が、そのサーバーでアクティビティを利用するすべての利用者に表示されます。ライブラリに追加していないご自身のプレイリストも同様です。
  • ライブラリ: ライブラリに追加されたプレイリスト（名称・タグ・収録トラック）と、追加した利用者のユーザー名・アバターは、そのサーバーでアクティビティを利用するすべての利用者に表示されます（プレイリスト作成者と追加した利用者のユーザー ID もアクティビティに送信されます）。

4. 情報の保存と保存期間

「取得する情報」のうち、Discord の識別情報、サーバー情報、再生履歴、プレイリスト情報、ライブラリ共有情報、アクティビティの設定は、開発者が管理するサーバー上のデータベースに保存します。このうち、再生履歴、Discord の識別情報、サーバー情報、アクティビティの設定は、期間を定めずに保存しており、自動では削除しません。ただし、サーバー情報のうちサーバーごとの設定は、本サービスがそのサーバーから退出したときなどに削除されることがあります。プレイリストとライブラリ共有情報は、本サービス上で削除されるまで保存します。お問い合わせの内容は、対応に必要な期間、メールとして保存します。動作ログの保存期間は「ログの取り扱い」のとおりです。本サービスの提供を終了した場合（アルファ版・ベータ版のみを終了した場合は、その版について）は、法令により保存が必要な情報、お問い合わせ・ご請求への対応の記録、および特定の個人を識別できないように集計・加工した統計情報を除き、本サービスが保存している情報を削除します。保存されている情報の削除をご希望の場合は、「開示・訂正・削除等のご請求」の方法でご請求ください。

5. 第三者への提供

開発者は、取得した情報を販売・貸与することはなく、個人情報の保護に関する法律その他の法令で認められる場合を除き、ご本人の同意なく第三者に提供しません。なお、「他の利用者に表示される情報」に記載した情報は、本サービスの機能として同じ Discord サーバーの利用者に表示されます。利用者は、本サービスを利用することにより、これらの情報が同じ Discord サーバーの利用者に表示されることに同意したものとします。また、「外部サービスとの通信」に記載のとおり、外部サービスを経由して情報が処理される場合や、利用目的の達成に必要な範囲で情報の取り扱いを外部の事業者に委託する場合があります。特定の個人を識別できないように集計・加工した統計情報は、本項の対象外とします。

6. 外部サービスとの通信

本サービスは、機能の提供のために以下の外部サービスと通信します。

  • Discord: BOT の動作、アクティビティの認証（アクセストークンの取得、ユーザー情報と参加サーバー一覧の取得）、アバター画像の取得のために Discord と通信します。アクティビティの通信は Discord のプロキシを経由します。
  • Cloudflare: 本サービスのウェブページ（本ページを含みます）とアクティビティの通信（認証用のアクセストークン、ユーザー ID、操作内容を含みます）は、Cloudflare, Inc.（米国）のネットワークを経由する場合があります。また、これらのウェブページとアクティビティの画面には Cloudflare Web Analytics の計測スクリプトが組み込まれており、閲覧したページの URL・参照元・ブラウザの種類・IP アドレス等の情報が、利用者の端末から Cloudflare, Inc. に直接送信され、同社によって処理される場合があります（Cookie は使用しません）。開発者は、同社が集計した統計情報を、本サービスの利用状況の把握や統計情報の作成など「情報の利用目的」に記載した目的のために利用します。同社による情報の取り扱いについては、Cloudflare のプライバシーポリシーをご覧ください。
  • YouTube・ニコニコ動画・SoundCloud・Bandcamp・SUNO など: 楽曲やプレイリストの URL・検索語・ID のみを送信します。利用者の Discord ユーザー ID など個人を特定する情報は送信しません。各サービスの情報の取り扱いは、それぞれのプライバシーポリシーに従います。
  • YouTube API サービス: 本サービスは、動画・再生リストの情報（タイトル・サムネイル・再生時間など）の取得に YouTube API サービスを使用しています。送信するのは動画・再生リストの ID のみです。Google による情報の取り扱いについては、Google プライバシーポリシーをご覧ください。
  • サムネイル画像: アクティビティに表示する楽曲のサムネイルや Discord のアバター画像は、本サービスのサーバーが配信元から取得して表示します。そのため、アクティビティの利用によって、利用者の IP アドレスなど端末の情報が画像の配信元へ送られることはありません。なお、BOT が Discord に投稿するメッセージ内の画像（楽曲のサムネイル、曲を追加した利用者のアバター）は、Discord が取得して表示します。

また、開発者は、本サービスの運用・管理、不具合調査・障害対応、および開発・改善のために、外部の事業者が提供するクラウドサービスや、AI を利用した開発支援サービス（米国の事業者が提供するものを含みます）を利用しています。その際、動作ログ、データベースに保存された情報および設定ファイルの内容の一部（Discord サーバー名・サーバー ID、ユーザー名・ユーザー ID、楽曲のタイトル・URL、再生履歴、日時など）が、これらのサービスに送信され、処理される場合があります。開発者は、これらのサービスの利用を、利用目的の達成に必要な範囲での情報の取り扱いの委託として行います。利用するサービスは変更されることがあります。

7. Discord アクセストークンの取り扱い

アクティビティの認証では Discord のアクセストークンを利用します。アクセストークンは、アクティビティの利用中に利用者の端末のメモリ上に保持され、本サービスへの接続時の本人確認と参加サーバーの確認にのみ使用します。開発者のサーバーは、アクセストークンをデータベースやログに保存しません。

8. ログの取り扱い

障害解析などのため、本サービスは動作ログを記録しています。動作ログには、Discord サーバー名・サーバー ID、スラッシュコマンドで曲を追加した利用者のユーザー名、楽曲のタイトル・URL、日時、本サービスへのリクエストの内容（ユーザー ID を含むアバター画像の URL など）が含まれることがあります。動作ログは開発者が管理するログ管理基盤に保存され、30日を経過したものは自動的に削除されます。ただし、本サービスの実行環境に残る動作ログは、サービスを再構築するまで保持されます。

9. 安全管理措置

開発者は、取得した情報の漏えい等を防ぐため、次の措置を講じています。

  • データベースおよび管理機能へのアクセス権限は開発者のみが保有・管理しており（「外部サービスとの通信」に記載した開発支援サービスを開発者の管理下で利用する場合を含みます）。
  • アクティビティでは、Discord の認証により利用者を確認し、利用者が参加しているサーバーの情報のみを表示・操作できるようにしています。
  • アクティビティとの通信は HTTPS（WSS）で暗号化しています。
  • Discord のアクセストークンは、データベースやログに保存しません。
  • 外国（米国）の事業者である Cloudflare, Inc. のサービスや、米国の事業者が提供する AI を利用した開発支援サービスを利用しており、利用者の情報が米国で取り扱われる場合があります。米国の個人情報の保護に関する制度を把握したうえで、上記の措置を講じています。米国の制度については、個人情報保護委員会のウェブサイトで公表されている情報をご参照ください。

Cloudflare, Inc. および開発支援サービスを提供する米国の事業者による情報の取り扱いが外国にある第三者への個人データの提供に当たる場合に備え、開発者は、各社が個人情報の保護に関する法律第4章第2節の規定により講ずべきこととされている措置に相当する措置（以下「相当措置」）を継続的に講ずるための体制を整備していることを、各社の利用条件およびデータの取り扱いに関する定め（Cloudflare, Inc. については、同社のデータ処理に関する付属書（Cloudflare Data Processing Addendum）および同社が取得している国際的なプライバシー認証（Global CBPR・Global PRP）を含みます）により確認しています。開発者は、法令に従い、各社による相当措置の継続的な実施を確保するために必要な措置を講じます。ご本人から求めがあった場合は、法令に従い、その措置に関する情報を提供します。ただし、提供することにより開発者の業務の適正な実施に著しい支障を及ぼすおそれがある場合は、その全部または一部を提供しないことがあります。

プレイリスト（収録曲と、サーバーのライブラリへの登録を含みます）は、アクティビティからいつでもご自身で削除できます。再生履歴・Discord の識別情報・アクティビティの設定など、それ以外の情報について、利用目的の通知、開示（第三者提供記録の開示を含みます）、訂正・追加・削除、利用停止・消去、第三者への提供の停止（以下「開示等」）をご希望の場合は、「運営者・お問い合わせ先」のメールアドレス宛てに、Discord のユーザー ID とご請求の内容を記載したメールをお送りください。開示等のご請求は、この方法に限り受け付けます。ご本人確認（ご請求に係る Discord アカウントからのご連絡をお願いすることがあります）のうえ、本サービスが保存している該当情報を対象に、法令に従って対応します。代理人によるご請求の場合は、代理権を確認できる資料をあわせてお送りください。開示は、原則として電磁的記録をメールでお送りする方法で行います（ほかの方法をご希望の場合は、ご請求の際にお知らせください）。手数料はいただきません。なお、削除後に本サービスを再度ご利用になると、その時点の情報があらためて保存されます。動作ログは、法令上対応が必要な場合を除き、個別の削除の対象外とします。
